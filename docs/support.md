# Barefoot — Support

A one-screen companion for Bluetooth scales that broadcast their weight (Chipsea
/ OKOK chipset, e.g. scales sold with the "OKOK International" app).

## Common questions

**It says "no data yet" while I stand on the scale.**
Force-quit the manufacturer's app. These scales accept one listener at a time, and
the original app usually grabs it.

**The weight appears but nothing is added to Apple Health.**
Check Settings → Health → Data Access & Devices → ScaleWeight → turn on *Body Mass*
write access.

**No weight at all.**
Scales of this type only advertise while measuring. Keep the app open, stand on
the scale barefoot, and wait for the reading to settle.

**My scale is not supported.**
This app speaks the four known Chipsea broadcast formats. If yours differs, the
raw frame stays visible at the bottom of the screen — send it and it can be added.
